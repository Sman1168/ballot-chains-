Tamper-evident e-voting prototype

Ballot Chain

Voters sign in with four details, one page at a time, plus a phone code. Their ballots are sealed into a hash-linked chain. Edit a recorded vote and the audit catches it. This is an example election you can reset at any time.

Voter access

Sign in to vote

Sign-in asks for your full name, phone number, NIN and voter's card number, each on its own page, then a one-time code sent to your phone. Only salted hashes of these details are kept.

Demo accounts for testing

Ledger and tamper test

Sign in and cast a few votes (a block seals every 3 votes). Then use the red buttons to play the attacker. The audit recomputes every hash from the stored data and flags the first block that no longer matches. Re-mining a block fixes its own hash, but the next block's link to it breaks, so try it on a block that is not the last one.

Simplified for teaching: everything runs in this browser tab, with no server, no real NIN or INEC lookup, no network consensus, low proof-of-work difficulty and a trusted registrar. A real system would verify identities against official records on a server and use a slow password hash.

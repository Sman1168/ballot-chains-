Tamper-evident e-voting prototype

Ballot Chain

Register voters, cast ballots, and watch them sealed into a hash-linked chain. Then edit a recorded vote and see the audit catch it. This is an example election you can reset at any time.

Registrar

Each voter gets a secret credential. Only its SHA-256 hash goes on the eligible list, so the ledger never holds names.

3. Ledger and tamper test

Cast a few votes above to fill the ledger (a block seals every 3 votes). Then use the red buttons to play the attacker. The audit recomputes every hash from the stored data and flags the first block that no longer matches. Re-mining a block fixes its own hash, but the next block's link to it breaks, so try it on a block that is not the last one.

Simplified for teaching: single browser, no network consensus, low proof-of-work difficulty, trusted registrar, no digital signatures or coercion resistance.
